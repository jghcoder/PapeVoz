# ✂️ Papelería La Escuadra — Punto de Venta con Voz

Sistema de punto de venta basado en Gradio con reconocimiento de voz en español mexicano.

## Características
- 🎙️ Reconocimiento de voz (dictado de pedidos)
- 🧾 Carrito con cálculo automático de totales
- 💾 Historial de ventas en SQLite
- 📊 Dashboard con gráficas de ventas
- 🔊 Síntesis de voz (lee el total en voz alta)

## Instalación local
```bash
pip install -r requirements.txt
python app.py
